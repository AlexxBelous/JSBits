У вас есть массив чисел, которые возвращает функция - randomNumber.
Необходимо написать функционал, который бы делал следующее:
  • - при нажатии на кнопку получает массив чисел
  • - создает для каждого числа элемент
  • - и добавляет его в уже существующий список ul
  • - проверяет, идут ли числа подряд (каждое следующее число должно быть на 1 больше предыдущего).
  • - для каждого числа, которое нарушает последовательность, добавляет класс "unsorted".
  • - перед каждым запуском очищает предыдущие элементы списка.
  • - запуск должен происходить при нажатии на кнопку "checkBtn".
